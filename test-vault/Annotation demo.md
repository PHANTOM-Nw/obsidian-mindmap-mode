# 注释效果演示

## 技术
: 注释附在当前节点下方，不占用独立分支。

### 泛化性与鲁棒性
: 泛化性：技能在不同本体状态、不同环境、不同对象上的迁移能力。这是一条较长的说明，用来检查文字超过节点宽度时是否自动换行。
: 鲁棒性：技能受到干扰或执行失败后的应对能力。
:
: 二者都涉及模型面对未见情况时的适应能力。

### 在线自适应
: 模型在应用过程中逐步改善表现。
: **加粗**、*斜体*、`代码` 和公式 $x^2$ 均可显示。
